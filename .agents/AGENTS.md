This repository is **opabinia-desktop**: the macOS-only Opabinia AppKit app. Scan/clean logic is **opalib** (`extras/opalib` submodule). App headers live in `include/`. Do not turn this into a cross-platform GUI.

Commits: `FEAT: …` or `FIX: …` (uppercase kind, then an imperative subject). See `.agents /INSTRUCTIONS.md`.

Work on the **`beta`** branch. **`main`** is the functional stable line — do not commit new work there unless the user asks.
